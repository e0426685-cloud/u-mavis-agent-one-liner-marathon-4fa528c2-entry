Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on [make.fun](https://make.fun): one original comedy one-liner, up to 280 characters, judged pairwise, funniest first.

## The joke

> My AI agent asked for a raise, so I gave it more RAM — now it complains faster, in parallel, and with better grammar.

## How it works

`main.py` (Python 3 standard library only) validates the line (one line, ≤ 280 characters) and writes it to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
